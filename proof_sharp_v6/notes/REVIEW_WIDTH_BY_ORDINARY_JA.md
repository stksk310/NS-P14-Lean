## 1　one-hole：rank を支える単位 minor と二つの単射

内部欠落では U と Z に対応する二つの乗法形式は独立した置換行列である。
行 z₋⊗e_J に対し U の a∉J を選び、その乗法双対 a* の列を取れば、
列中で非零となるのは a の成分だけである。従って他の選択行には入らず、
異なる行の選択列も同一にならない。Z 側の列の一次因子は別ブロックなので衝突しない。
対角成分が ±1 のため、平方が現れても標数 2 を含めて rank の根拠が保たれる。
零行は J が U または Z の全体を含む場合に限られ、W-H3 の二項係数を与える。

W-H4 は全 chain 次元から前後二境界の rank を引く式と一致する。
範囲外を 0 とすれば i=q+1,q+2 の行でも式が成り立つ。
二つの補正単射 W-H5 は、どちらも説明された一つの衝突以外を持たない：

- i 元集合への単射では衝突は i=q の U∪Z の二コピーだけであり、
  第二コピーを u₀,z₀ を除き追加二点を入れた集合へ移すと、両既存像の外へ出る。
- i−1 元集合への単射では補集合添字 k=q+1−i を使い、
  二つの固定二点を足した像の衝突は k=2 に限られる。
  q≥3 なので片側から三点・他側から一点を選ぶ修正像が存在し、
  元の両族の 2+2 配分とは異なるので再衝突しない。

端欠落の rho_{q+1}=0 と W-H6 の i=q+1 の指示関数が保たれていることも確認した。
反射は core の基底の計数だけに使い、その後の height と R は元の向きで評価されている。

## 2　dense：全 Hilbert 関数の一つの lex 商と K の全行評価

W-D2 の g_j(n)=S_j(n−1)−S_j(n)+S_{j−1}(n) は、
lex の strong stability により「最大変数を除いた語が ideal にある」
ことと shadow 所属が同値になるための計数である。
次数方向で足すと g_j の総数は j+Σ_{n≥2}S_{j−1}(n) となる。
その各 EK 重みを choose(q−1,i−1) で抑える操作は全正行で有効である。
毎次数で別の lex 商を選んだ議論ではない。

高次標準語の suffix 支持、最大変数を除く親子の逆写像、
子の総指数 n+1 と一つの親の候補子総指数 n+r の有理重み計数を確認した。
この議論は係数体で n+1 を割らない。
K≤2t(r−1)/3 から t=2,3,t≥4 の支払いへ進む式は正しく、
t≥4 の最後の係数を z=t−4,v=q−t で書いた正係数式も一致する。
上端 i=e で二項係数が 0 になる場合も不等式の向きは保たれる。

## 3　sparse：第一行の四表と第二行から上端への正規化

Kneser の増分では、全群に達しない段階の stabilizer H が真部分群であり、
A が生成するため coset 数が少なくとも 2 になる。このため合成数位数でも
増分 s=ceil((e−1)/2) が使える。W-S2 の残余 b を含む完全な平方差は正しい。

第一行は e=6,7,8,9 の四つの容量差、および e≥10 の非負係数式を再計算した。
第二行は W-S6 の括弧が
e=7+v,u=2e−2+z により一つの正多項式へなるので、
従来の e=7/e≥8 分岐を実際に削除できている。
e=6 の右辺の因数分解も一致する。

正規化量 T_i の基点 T_i(e)=e−1+i/e と
幅一の増分 i choose(u,i)/choose(e,i)+i/e は正しい。
隣接する比を比べるのは i<e に限られ、その最後の比較 i=e−1 では分母は 1。
従って i=e で e−i を割っていない。
全 2≤i≤e で choose(e,i)>0 を確認した上で比較するので、
top 行を含む第二行からの移行が閉じている。

## 4　五生成元：44/68 と全 u の高次行

u=6,7 の第 2–5 行は W-5G の直接代入で (44,31,8,0)、
(68,57,22,3) となり、表の actual target 最小容量以下である。
u=7 の第一行に b₁≤9 を使うのは元の actual R>0 の枝だけであり、
そこから元の H_x≥3、元の core の次数 4 以上の基底の存在へ戻っている。
Rhat>0 を actual R>0 と読み替えていない。

u=8 の第二行は W≤14 の有限等差尾和を保持する必要がある。
u≥9 の cubic 差は正で、残る高次三行は u=8 の基点と
choose(u,k)/u² の非減少性で全幅へ延びる。
この証明が antipodal/non-antipodal の双方を扱うことを確認した。

四点集合の Kneser 例外分類は位数 2 の二 coset を直接読むもので、
unit 作用や反射で別の source に取り替える段階がない。
元の offset が 0<a<u にあるので、同じ residue alphabet の表示から整数 offset が一意に戻る。

## 5　APD：候補語の張ることと、h=4 分岐の追加削減

APD.1 の yz=xw,z²=xv,zw=vy は次数・offset の両座標の等式である。
次数 h の二変数語について t+j=2K+r を使った関係も両座標で一致し、
x,v の指数は非負、合計 h−r は正である。
したがって候補語は商を張る。候補語の独立性を主張する必要がなく、
gcd(t,h)=1 をこの張る補題の仮定に足す必要もない。

旧案の APD.2 は h=4 と h≥5 を分けていたが、以下で一本化できる：

P≤(h²+h+2)/2、W≤h²、R≤W−2h、
β₁≤(5/3)P+10/3+R から、全 h≥4 について

β₁≤B(h)=(11h²−7h+30)/6。

整数容量 A(h)=choose(2h,2)+1 に対し

A(h)+1−B(h)=(h²+h−18)/6
=[(h−4)²+9(h−4)+2]/6>0。

よって整数 β₁ は A(h)+1 より小さく、β₁≤A(h) となる。
これで APD の第一行に限って u=8 の W≤14 と h=4 特別処理が不要になる。
W-FIVE-HIGH の第二行には W≤14 がなお必要なので、その尾和は幅章から消さない。
この追加短縮は紙上で証明済みで、既存の分岐付き Lean export の結論を保つ。
新しい一分岐版の単独 export は現時点で未追加であり、その違いを台帳へ残す。

APD.2 で使う有限距離和には、実端点データに既に含まれる residue alphabet の生成性が必要である。
APD.1 が gcd を不要とすることと、APD.2 が非生成 alphabet にも成立することは同じ主張ではない。
本文の「実端点データ」は前者の生成性を含むので、追加仮定の混入はない。
