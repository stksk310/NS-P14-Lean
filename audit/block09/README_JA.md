## 数学的な照合

| 対象 | 監査した内容 |
|---|---|
| `Ring` / `IdealPowers` | Rはactual半群の`AddMonoidAlgebra`。正元イデアルは正元単項式の生成イデアルとして定義される。数値orderで切る別のイデアルと実冪の両包含を証明しており、冪を数値閾値と定義して済ませていない。 |
| `RingCoordinates` | 定数項の積保存は指数の非負性に基づく。定数項写像の全射性と核=正元イデアルを証明。極大性は体に限定される。actual原子の和因子を取り出し、原子単項式による生成も証明する。 |
| `GradedPieces` | 分子は実冪をk加群に制限したもの、分母はその内部の実次冪。exact-order係数抽出の核と全射性から、実商と有限支持座標の線型同値を構成する。 |
| `GradedBasis` | conductor Cの最小性は不要。v≥(n+1)(C+1)ならn個のC+1と正の残りに分解でき、order(v)≥n+1。有限な指数集合で添字付けされた基底を実商へ移し、基底ベクトル=初期単項式を証明する。 |
| `GradedProduct` | 代表の左右それぞれを次冪だけ変えた場合の消滅を証明し、双線型積を両方の商へ降ろす。単項式積は次数和の層の実積で、orderの余分な跳びで0になる。 |
| `TangentAction` | 上記の積の片側を[t^m]で固定した実線型写像。係数1の初期単項式がその核に属する条件が、数値`Terminal`と同値になる。 |

`orderIdeal_eq_pow`の逆包含はorderを実現する正元分解の単項式積、冪の降下性、支持単項式の和を使う。
Block08の最長正元分解は原子分解を実現するため、原稿の最長生成元表示と対応している。
任意の可換係数環でこれらの冪・商・基底・双線型積を構成できる。
単項式の所属の逆向き・非零判定には`Nontrivial k`、極大性には`Field k`が必要で、実装・説明ともに明記されている。

## 独自の境界確認

`RingChecks.lean`はactual半群⟨4,5,11⟩を独立に定義する。
11は原子でorder(11)=1、order(15)=3、m=4なので、[t^11]は自分の次数で非零だが実際のx作用で0になる。
一方[t^4]はx作用で非零。この確認は任意の非自明可換環を許す。

係数相殺では`t^11`は𝔪²に入らないが、`(t^11+t^15)-t^11=t^15`は𝔪³に入ることを検査した。
零環ℤ/1ℤでは全初期単項式が0になるため、非自明性の仮定は実質的である。
ℕの半群環をℤ/4ℤ上で取ると、係数1の[t]²は非零だが、(2[t])²=0。
従ってsourceの非零判定を「任意の非零係数」に拡張してはいけない。
次数0の指数は0に限られ、C=0・m=1でも有限性の境界が成立することも検査した。

有限計算では、入力生成元の最長表示DPと、全正元集合のBoolean畳み込みによる実単項式イデアル冪を別々に計算した。
係数つき多項式の通常の畳み込みをexact-orderへ射影した結果が、単項式のlive/killed積と一致する。
左右の代表に次冪の多項式を加えても結果は変わらない。
標数2の相殺とℤ/4ℤの冪零係数も明示例で確認した。
これらは有限の追加検査であり、Leanの一般定理の代用でも、核全体の基底のLean実装でもない。
