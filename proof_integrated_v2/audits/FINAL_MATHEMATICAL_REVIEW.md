## 判定と限界

**確認した範囲で未解決の数学的 blocker は見つからなかった。**
採用した簡約は、実際の source、実際の completion、全 Betti 行、および任意体という
元の主張の範囲を保っている。とくに §12 の一般端点補題への集約によって
`d>1`、合成数幅、`gcd(m,u)>1`、あるいは `du>=m` を誤って落としてはいない。
§14 は明記された真正狭幅だけに適用し、幅4 patch も `m>=6` を保っている。

これは統合後の論証と接続の独立レビューであり、公刊済みの専門査読や Lean の
kernel 検証を意味しない。公刊入力は §1.2 の外部定理として残る。本レビューは
それらの文献全体を再証明していない。また旧3501行全文の新たな逐行再査読を
主張しない。旧稿との比較は、残された ordinary 鎖、旧付録Bの小 ordinary、
共通端点の旧 F1–F8 / 付録C、一欠落幅、および幅4の旧 B2–B4 を中心に行った。

## 1. 主張、容量、ordinary の保存

- §1.3 の算術列公式は商の正 Betti 行を使っており、ordinary の
  `i binom(m,i+1)` と整合する。剰余パラメータに関する最小値は境界
  `D=i` / `D=i-1` にあり、幅について非減少な `F_i^min` を使える。
  §13 は実効幅 `min(du,m-1)>=u` からこの下界を引き、§14 は物理幅 `V=du` を使う。
  固定した `m` に対する個々の剰余公式の単調性を誤って仮定していない。
- §2–10 の数値座標、jump strata、実際の塔、同じ cut の同じ資源列を保持している。
  `T` と `N` 全体の同型を仮定せず、等 jump の strata のみを比較している。
  非 Apéry head の次数が3以上であること、jump の伝播方向、
  `H_0=delta`、`H_1<=M-a`、`S<=delta mathcal V` の使用方向に問題を見なかった。
- §6 の monomial 初項化は Koszul 境界の block 三角 rank 比較で正当化されており、
  単項式の場合の minor の係数は `+/-1` である。有理重みは次元の数値的評価である。
- §7–8 は connecting rank / spectral sequence の損失を減算し、残りを鎖群次元で
  上から評価する。商の Betti 単調性や spectral sequence の退化を仮定していない。
- §9 の三本 cut の第二行評価には §5 の `H_1<=3 delta` も使える。
  具体的に `W_2(1)=8/3`、`W_2(t)<=3/2 (t>=2)` なので
  `delta+(8/3)H_1+(3/2)(S-delta-H_1)<=3 delta+(3/2)S` となる。
  これは本文の「同じ重みから」の省略を補う計算であり、追加仮定ではない。
- §10 は `j=r` を含む。ordinary 比較で上端行が抜ける箇所は見つからなかった。

## 2. §11：固定 cutoff scalar

`e>=10, r>=4, delta>=a_r` を維持している。`D=floor(a_r/2)+1` は `delta` に
依存しないが、重みから `alpha` を引いた後、`t>=D` の係数は非正になる。
この tail を落とす操作は正しく、`H_1<=M-a_r` を一度だけ使っている。
資源列の台が cutoff 内に入るという仮定はない。

基点の6個の小 rank と `H_23` anchor、`r>=10` の障壁帰納は残る。
`T_1<=T_r` の向き、凸関数の端点補間の向き、`D` の floor の扱いは正しい。
固定 `D` に対する前進差分から

`G(10,a_r+t)=g_0+t b_0+(1-alpha) binom(t,2)`

を得る。`t` は非負整数であり、最後の二項係数は非負である。
`g_0>0, b_0>1/4, 0<alpha<1` と `e` 方向の正 slope により全域へ延長できる。
`e=9` への拡張は主張していない。§16 は実際の cut について
`delta>=binom(r+1,2)` を先に得てから本節を適用する。

## 3. §12：一般端点模型と actual kernel

- 仮定 `q>=2, u<m` の下で最小生成性を証明している。
  `du<m` は不要であり、§13 の広い定義域にもそのまま適用できる。
- core 単項式 `(n,B)` の像は数値指数 `nm+dB` の最大 order で決まる。
  同じ次数の異なる offset の像は混ざらず、actual kernel は core 基底の一部で張られる。
- `(r,L,K)` 座標と `E=k[x,v]` 上の直和は加群の同型である。
  `u` 個の内部文字の prefix 消去は零和部分語を端点へ替える操作であり、
  全ての residue に長さ `<=u-1` で達する議論も gcd 条件で保証される。
- 競合は正確に `(n+jd,B-jm)`。clamp は第一座標だけに必要で、
  `m>u` により carry は正である。actual kernel は `N_s=M_s intersect T_s` であって
  `T_s` 自体に置換していない。
- 有限停止には `gcd(m,u)=1` を使っていない。
  `j>J_0` の純 `v` 領域で周期 `u/gcd(m,u)` だけ戻した先行生成元が後続を割る。
  純 `v` 冪の存在は保たれ、角を数える際に pure `x` 冪や Artin 性を仮定していない。
- 角の順序 `A_i` 増加 / `B_i` 減少から、socle 候補は
  `(A_{i+1}-1,B_i-1)` である。`M_s/N_s` から `E/T_s` への単射は socle にも単射なので、
  新しい角を誤って無視することなく `R<=W-u` が得られる。
  第一座標の範囲から別の上界 `u max(H_x-2,0)` も得られる。
- `P_G` は生存する極小点だけの個数であり、`P_C` と区別される。
  端点 homology は `(P_G,P_G+R,R)`。実際の
  `Q_C -> Q_G` の核長 `P_C-P_G` に対する Tor 項が (E19) に残るため、
  (E21) の `P_C` への置換は正当である。`P_C+R<=W` は使わない。
- §13 の Veronese 型 core と本節の core は、
  `(n,B) -> s^(un-B)t^B` という加法的で単射な次数付き写像で同型である。
- 二内部変数の場合にのみ単項式 quotient / socle の直接計数を主張する。
  一般 `q` では Artin 商への incidence / Koszul 評価を使い、誤って単項式環と同一視しない。

## 4. §13：幅側の保持された分岐

最小幅、一欠落幅、密な幅、疎な幅、および五生成元の構造分岐が全て残っている。

- 一欠落幅では二フォームの実整数行列から単位 minor を選んで rank を出す。
  平方の係数も1なので標数2で消えない。二つの包含写像の衝突修正は有効である。
  端欠落の上端 `i=q+1` の指示関数も残っている。
- 密な幅では一つの Hilbert 関数に対する一つの lex ideal を使う。
  prefix の欠落数から `H_x<=t`、Kneser を使わない長さ2到達から `W=q+1+2t` を得る。
  core の反射で actual `R` を反射したものへ取り換えてはいない。
- 疎な幅の Kneser 増分は stabilizer の coset 数を用いており、合成数位数にも成立する。
  新しい第一行4表と `e>=10` の恒等式は `u>=2e-2` を覆う。
  高次行の `T_i(u)` は上端 `i=e` まで定義され、第二行から全高次行へ移せる。
- `e=5,u=7` の `b_1<=9` は `R>0` のときだけ使われる。
  `R=0` は別の容量で払う。次数4以上の core 基底の存在から tail を少なくとも1とする論証も有効。
- `e=5,u>=8` の非 antipodal / antipodal 分岐を保持する。
  antipodal の (W25) は `gcd(t,h)=1` により異なる短い内部次数を区別でき、
  第 `h` 次で端点表示が現れるため、全 quotient 基底の記述になっている。
  両分岐の高次行は共通の粗い上界で払える。
- 密な範囲 `u<=2e-3` と疎な範囲 `u>=2e-2` は隣接し、
  `e=5` も `u=4,5,6,7` と `u>=8` で尽くす。

## 5. §14：全 d の N4 と有限部分

真正狭幅 `m>=du+2` を保持し、全 `d>=1` を共通の (N4)–(N5) で扱う。
反復 Kneser の非自明 stabilizer の場合も `A` は少なくとも二 coset を占めるので、
`W<=1+floor(u^2/4)` は素数幅に限られない。

二変数 downset の socle antichain は全ての次数 `sigma_C-1` の単項式を含ませる。
従って `binom(sigma_C+1,2)<=P_C` は正しい。純軸の shortening と
Savchev–Chen の混合語論証は端点表示を作る操作であり、actual order の誤った
同一視を使っていない。この二つの上界から `sigma_C<=floor(u/2)+2` と
全 `u>=13` の第一行容量を得る。

高次行の三つの差分多項式は全係数が正である。`u=3,4,5` は別途処理され、
`u=4,V=4` の第3行は粗い一般下界の範囲外であることを正しく避けている。

有限196組は向きを同一視せず数えている。例外は粗い第一行上界が不足する
`(u,a,b)=(3,1,2),(4,1,3)` だけであり、`d>=2` は物理幅の容量で払う。
`d=1,u=3` は source=target、残る幅4 patch は `m>=6` に限定される。
幅4 patch の標準余りの独立性、実競合の `x` 閾値が0になる計算、
全 `j>=1` の `v` 閾値の単調性、4つの剰余別生成元数を確認した。
生成元数は `6,8,8,6`、実 target は `7,10,9,8` であり、
誤った一様な `beta_1<=7` は主張していない。

## 6. §15 と §16：残存 ordinary と合成

旧付録Bとの比較で、exact offset 列、全 `m` 本の自由列、first-hit の伝播、
actual Tor cutoff、`P_x` の二次上界、truncated lex の terminal 項が保持されている。
`widehat h` の数値半群としての実現可能性を仮定していない。

最大 first-hit の証明は隣接する profile 間の単調性を仮定せず、
最後の slot の増分で高々 `k-1` 個の負 slot を払う。
`rho=m-2` と `k=1,rho=m-3` も独立に処理している。
5本の無限 tail は正の有理 anchor と前進差分から全 `m` へ延長される。
第二行から高次行への正規化比較も `i=e` まで届く。

83組の範囲は `5<=e<=9, e+10<=m<T_e` であり、§16 の
`r>=4 -> delta>=10` から必要な残余を正確に受け取る。
`e>=10` は §11、`r=2,3` は §9 で閉じる。
狭幅では `e=3` の公刊比較、`e=4` の §14、`e>=5` の §13 を使う。
`w=m-1` を含む ordinary 側との境界に整数幅の漏れはない。
`e=1,2`、第0行、および source の表示変数数を超える行も明記されている。

任意体性について、新しい有理数は次元の数値的重みだけであり、体内で割っていない。
一般一次形式は §4 で同標数の無限純超越拡大へ移して選び、Betti 数の体拡大不変性で戻す。
異なる標数間の actual Betti 数の一致は仮定しない。
