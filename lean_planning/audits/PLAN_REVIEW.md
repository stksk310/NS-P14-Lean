## 工数の読み方と算術

| 作業群 | 再計算した人日 |
|---|---:|
| M01–M04 | 235–660 |
| M05–M09 | 380–1,120 |
| M10–M12 | 130–345 |
| M13–M14 | 70–190 |
| M15–M17 | 95–280 |
| M18 | 8–25 |
| 18モジュール計 | 918–2,620 |
| M00 の2–5人日を加算 | **920–2,625** |

1人日を熟練者＋AIによる集中作業約6時間と定義し、各行は前提完成後の追加工数とする。
公刊証明を条件付き引数にしても、M05 等の actual target・最小表示・添字の接続費は残る。
M05–M09 を丸ごと差し引いた、過少な条件付き総工数は提示していない。
公刊7入力の追加配賦表も、M05 は50–150＋30–70＝80–220、
M07 は35–95＋35–105＝70–200となり、全7入力は380–1,120人日で元の枠と一致する。
これらも原典実装の実測値ではなく、各モジュールの内数であると明記している。

試作は3–5、3–5、4–10人日の合計10–20人日で、関連モジュールの内数と明記する。
別の二生成元縦断面15–40／40–100人日以上も内数であり、初回10–20人日での全完を約束しない。
月16人日の仮定で920–2,625人日を約58–164か月、約5–14年へ換算する算術は整合する。
これは未校正の工数換算であり、納期・必要年数の下限・人数で単純除算した工程ではない。

**見積の限界：** 各モジュールの数値には、実装パイロットの速度データや統計的な裏付けはない。
数値レンジは実測前の企画判断であり、公開ソースの宣言数から導いた客観的な所要量ではない。
計画書自身がこの限界を明記し、10–20人日の校正と再見積りを次の工程にしているため、
現段階の大枠として採用できる。モジュール別の細かい確率的信頼度は付していない。
とくに M02/M03 と公刊証明群は上限超過もあり得る。パイロット前に数値を納期へ格上げしない。
