# NS-P14-Lean v1.0.0

The interval-completion comparison for total Betti numbers of numerical
semigroup tangent cones is formalized for every numerical semigroup, every
field, and every homological degree. Each tangent cone is presented over its
own minimal polynomial ring. Run20 and the final independent audit are complete.

Public theorem: `NSP14.NumericalSemigroup.p14_totalBetti_le_intervalCompletion`.
Minimum import: `NSP14.Main`.

The release preserves the audited tree at
`e72713965716d7f93f672034c6332a79b59b1c53`, with publication documentation,
licenses, citation metadata, and release automation added separately.
It does not modify any audited proof, dependency pin, existing manuscript,
verifier, evidence file, or historical audit ZIP.

Saved proof snapshot: `1a5c6bac9a4fd38a8bc5d13b4c7372e654466e6e`.
Final independent cold audit target: `a5e122a4d09536b1609c5faa8d419f8faf81671f`.
The saved verification reports 335 checks, 311 fixtures, 15,774 declarations,
and 1,019 modules, with only `propext`, `Classical.choice`, and `Quot.sound`.
There are no remaining required mathematical inputs or unresolved final audit
findings. Publication packaging checks these records and exact preserved bytes;
it does not constitute a new Lean execution or a new mathematical review.

`139105d28c7685a154cb3093f79edb2e16708099`.
