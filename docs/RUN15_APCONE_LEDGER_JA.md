# Run15 一般APの実半群環/接錐Betti一致

基準3e82d46fe2dcfdafb530802d8c78914e675c1c40。元のAPConeBettiGoalそのものをaudit/run15_apcone/ClosedGoals.leanで証明した。これで8目標中7目標が閉じ、一般APBettiGoalだけが未完。Run15全体は未完のまま同じrunで継続。

Semigroup.AlgebraHeadQuotientは任意数値半群の実t^mとprincipal idealを定義し、係数の移動から正則性、実Apéryでの係数消滅からideal所属を証明。ArithmeticSequence.HeadMultiplicationは公差dを保ち、和がApéryならorderが加法的となることをcanonical表現から証明。HeadQuotientMapは実代数半群環から実HeadAlgebraへのAlgHom、その全射性と核=(t^m)を構成する。AlgebraVariableOrderは同じ全最小原子の順と作用からnative complexと普通Torを同定。ConeBettiは商AlgEquivの非x多項式加群同型を構成し、実正則元によるKoszul縮約から全行Betti一致を得る。

これは環本体の同型や一般的なflat degenerationのBetti一致ではない。実際のApéry商と全変数表示、両方のregular reductionを用いた個別証明。任意元体・標数2・m5,d2,v3の非最大埋込次元AP、既に独立計算した最大埋込次元coneの値から代数的半群環への転送を受入検査する。

一般APBetti公式は残る。特定の初期単項式加群と同Bettiであるとの仮定は採用しない。原稿X_AP_CONEの代替証明はA68へ記録した。検証入口scripts/verify_run15_apcone.py --fresh-test-cache、全型・公理・旧原本不変・全受入・数値回帰はverification/run15_apconeへ保存。
