# NS-P14の追加簡約探索

2026年11月9日。現行の統合証明稿を保存したまま、証明可能な置換を探索した結果。

**さらに簡約できる。最大の成果はN4で、証明の全 \(m\)・任意体という範囲を保ったまま、長い支持分類と高次行の有限計算を取り除ける。** 以下は思いつきの候補ではなく、置換に必要な不等式を導出し、必要な有限計算を再実行したもの。ただし、まだ現行稿全体をこの構成に編集し直した版ではない。

## 1. N4の簡約の核

正規化したcoreを \(C=k[s,st^a,st^b,st^u]\)、\(Q_C=C/(x,v)C\) とし、
\[
P_C=\dim Q_C,\qquad
\sigma_C=\dim(0:_{Q_C}(y,z)),\qquad
R=\dim(0:_G(x,v))
\]
とする。全 \(d\ge1\)、\(du\le m-2\) に対して、現行の共通基礎は
\[
\beta_1\le P_C+\sigma_C+1+R,\quad
\beta_2\le2P_C+\sigma_C+3R,\quad
\beta_3\le P_C+3R,\quad \beta_4\le R,
\]
\[
P_C\le W,\qquad R\le W-u
\]
を与える。ここに三元巡回集合 \(\{0,a,b\}\) のKneser評価から
\[
\boxed{W\le1+\lfloor u^2/4\rfloor}
\]
を加える。

これにより高次行は全称の多項式不等式で閉じる。小幅 \(u=3,4,5\) も直接評価でき、actual orderの全 \(m\) 列挙と安定tail証書が不要になる。

第一行ではSavchev–Chenから、\(h=\lfloor u/2\rfloor\) に対し
\[
P_C\le\binom h2+2u-3
\]
を使う。二変数の標準単項式集合のsocleが \(s\) 個なら、その集合は少なくとも \(\binom{s+1}{2}\) 個の単項式を含む。従って \(\sigma_C\le h+2\) となり、全 \(u\ge13\) が紙上で閉じる。

残る \(3\le u\le12\) は196 offset組だけ。全 \(m,d\) に一様な上界を二つの独立実装で評価し、不足は \((u,a,b)=(3,1,2),(4,1,3)\) の二組だけだった。前者は同一targetまたは \(d\ge2\) の余裕で処理でき、後者は \(d=1\) の幅4だけ現行の剰余別証明を残せばよい。

KneserはP14全体で既に使う公刊入力なので、全体の外部依存は増えない。N4だけを独立に取り出すと、その証明にKneserを使う点は変更となる。Savchev–Chenを外せたという主張ではない。

完全な導出は [N4_SEARCH.md](N4_SEARCH.md)、独立点検は [N4_REFEREE.md](N4_REFEREE.md)。

## 2. Scalarはcutoffを動かさなくてよい

現行の \(D=\lfloor\delta/2\rfloor+1\) を、
\[
a_r=\frac{r(r+1)}2,\qquad D_r=\lfloor a_r/2\rfloor+1
\]
へ固定しても、同じ資源列の上界が全 \(\delta\ge a_r\) で有効である。
\(\alpha=(r-1)/(D_r+1)<1\)、\(t=\delta-a_r\) とすると、gapは
\[
\boxed{G_r(10,a_r+t;D_r)=g_0+t b_0+(1-\alpha)\binom t2}
\]
と書ける。既存の基点評価から \(g_0>0,b_0>1/4\) が従うため、偶奇ごとの帰納とcutoff変更差分が不要になる。

rank方向では
\[
B(r)=\frac r4+1+\frac9{2r}
\]
を間に挟む。\(r\ge10\) で \(\mathcal H_{D_r}<B(r)<T_r\) を短く証明でき、10次の多項式を使った閾値差分の証明が不要になる。H23のアンカーと、小さいrankの6比較はそのまま使う。

完全な導出は [SCALAR_SEARCH.md](SCALAR_SEARCH.md)。新しい恒等式は係数ごとに再構成して検算し、固定cutoffの351例の補助診断も通過した。全称性の根拠は表示した恒等式と不等式である。

## 3. 幅側にも局所的で読みやすい置換がある

内部変数数を \(q\)、core商の長さを \(P\) とする。既存のincidence評価で次数2を残すと
\[
\boxed{b_1(Q)\le\frac{q-1}{4}P+
                 \frac{(q+1)(q+2)(q+3)}{24}}
\]
を得る。新しい外部定理は要らない。

これにより疎な第一行の大きな偶奇多項式を、\(e=6,7,8,9\) の小さな4行表と、\(e\ge10\) の一つの正係数式へ置き換えられる。第2行以降の幅側証明はそのまま残せる。

5生成元の幅6/7も、同じincidence評価と既存のArtin上界で処理できる。幅7の \(R>0\) は高次数の非零成分を強制し、整数性から \(b_1\le9\) が従う。ここを無条件の \(b_1\le9\) に変えてはいけない。

完全な導出・置換する箇所・残す分岐は [WIDTH_SEARCH.md](WIDTH_SEARCH.md)。幅側は表に分けることが読みやすさの改善になるか、本文編集時に判断すればよい。

## 4. 安全に整理できる重複と、今は残す箇所

現行第12節F、NP、H、付録Cでは、coreからactual接錐への写像、競合ideal、端点Koszul移行を繰り返し証明している。任意の内部変数数について一つの共通補題を置き、N4はその二変数系として述べる形にできる。記号は \(Q_C,P_C,\sigma_C\) と \(Q_G,P_G,\sigma_G\) を区別して統一する。

次の点は、短さのために省略しない方がよい。

- coreの基底とactual接錐の単項式核の証明。
- 競合長が \(jd\) であること、負の閾値のclamp、\(M_r\cap T_r\)。
- kernel–Tor補償と任意体でのKoszul評価。
- 最後の幅4で、実際のtargetを使う四剰余表。
- 幅側の一欠落に用いる整数minorと包含写像。
- 5生成元の大幅におけるantipodal分岐。
- 小ordinaryの83組と5本のtail。今回これを取り除く証明は得ていない。

単にscalarの範囲を \(e\ge10\) から \(e\ge9\) に広げる試みは、同じ上界では失敗する点がある。これは評価法の限界であり、P14の反例ではない。したがって小ordinary側の枝は現時点で残す。

## 成果の状態

現行の約3,500行の統合稿とその証書は変更していない。本探索で確認した置換を実装するなら、共通基礎を一本化した上でN4、scalar、幅側の順に差し替えるのが自然である。全文の新しい行数は、実際に統合して参照関係を点検するまで確定させない。

本フォルダは次版への置換証明・独立点検・厳密計算を保存する。Lean形式検証は行っていない。

N4以外の置換も、[scalar・幅側の独立点検](SCALAR_WIDTH_REFEREE.md) で各適用範囲・恒等式・例外条件を確認した。[再実行記録](verification.json) に、実行結果と現行証明パッケージが不変であることを保存する。
