# N4：反射による有限証明書の圧縮と小さな紙上改善

調査対象は V02 の §12、§14 と、その196行の offset 証明書である。V02 本文・checker・証明書は変更していない。本ノートは独立した追加調査であり、§14 全体の差し替え案ではない。

**結論。** コアの反射を使えば196個の向き付き offset 対を **109個の代表計算**で保証できる。さらに既存の混合語補題から socle 評価を1改善すると幅11を紙上で除外でき、**151対・84代表**になる。幅3、4の三つのコア型も紙上で書き下せば、残る有限 checker は幅 \(5,6,7,8,9,10,12\) の **81代表**でよい。これは本調査で得た十分条件であり、最小件数との主張はしない。

## 1. コア反射の正確な範囲

\(0<a<b<u\)、\(\gcd(a,b,u)=1\) とし、
\[
 \rho(a,b)=(u-b,u-a)=(a',b'),\qquad
 C_{a,b}=k[s,st^a,st^b,st^u].
\]
次数・offset の半群に対する写像
\[
 (n,B)\longmapsto(n,un-B)
\]
は加法的な全単射で、生成元を
\[
 x\leftrightarrow v',\qquad y\leftrightarrow z',\qquad
 z\leftrightarrow y',\qquad v\leftrightarrow x'
\]
と移す。したがって次数付き環の同型
\(C_{a,b}\simeq C_{a',b'}\) があり、端点イデアル \((x,v)\) は \((x',v')\) に移る。
そのため
\[
 P_C(a,b)=P_C(a',b'),\qquad
 \sigma_C(a,b)=\sigma_C(a',b').                 \tag{S1}
\]
標準内部語の downset を \(D_{a,b}\) とすれば、より具体的に
\[
 (s,t)\in D_{a,b}\iff(t,s)\in D_{a',b'} .     \tag{S2}
\]
実際、内部語が同じ次数・offset の端点表示を持つことと、反射語が反射された端点表示を持つことは同値である。

§12 の座標 \(B=r+uK\)、\(n=L+K+\epsilon_r\) では反射は
\[
 r\mapsto-r\pmod u,\qquad (L,K)\mapsto(K,L).
\]
\(r=0\) の場合もこの式が成立する。したがって
\[
 H_v(a,b):=\max_{(s,t)\in D_{a,b}}
                \left\lfloor\frac{as+bt}{u}\right\rfloor,
 \qquad H_x(a',b')=H_v(a,b),\quad H_v(a',b')=H_x(a,b).       \tag{S3}
\]
これは剰余別 Pareto 極小点の両座標を交換する事実でもある。

巡回群の有向経路では、各ステップを符号反転し \(a,b\) の名前を交換すればよい。従って
\[
 \ell^{\rho}_{-r}=\ell_r,\qquad W^{\rho}=W.     \tag{S4}
\]

ここで同型なのは **斉次コアとその端点商**である。実接錐への写像は
\((n,B)\mapsto nm+dB\) を使うので、反射後は \(n(m+du)-dB\) となる。正の \(d\)、同じ \(m\) の実半群の同型や、その actual kernel の同型は導かれない。本ノートでは実接錐の Betti 数や actual \(R\) の反射不変性を一切用いない。

## 2. 二つの向きを一度に支払う上界

各向きの実接錐には、§12、§14 の向きを保った評価を**別々に**適用する。共通な \(P_C,\sigma_C,W\) と (S3) より、それぞれの \(R\) は
\[
 \min\{W-u,u\max(H_x-2,0)\},\qquad
 \min\{W-u,u\max(H_v-2,0)\}
\]
で評価される。そこで
\[
 \begin{split}
 \widehat R_{\rm sym}
   &:=\min\{W-u,u\max(\max(H_x,H_v)-2,0)\},\\
 U_{1,\rm sym}&:=P_C+\sigma_C+1+\widehat R_{\rm sym}
 \end{split}                                                     \tag{S5}
\]
と置けば、\(U_{1,\rm sym}\) は同じ \(m,d\) における**双方の実接錐**の第一 Betti 数の上界である。\(L_1(u)\le F_1(m,du)\) は両者に共通なので、各反射軌道の代表について
\(U_{1,\rm sym}\le L_1(u)\) を一度確認すればよい。

数の恒等式として
\[
 U_{1,\rm sym}(a,b)=\max\{U_1(a,b),U_1(\rho(a,b))\}.          \tag{S6}
\]
したがって旧証明書で双方が通る軌道は新しい上界でも必ず通り、新しい例外は生じない。一方、小さい方の高さで二方向を保証することはできない。例えば \(u=7\)、\((a,b)=(1,5)\) と \((2,6)\) は
\[
 (P_C,\sigma_C,W)=(9,2,12),\qquad
 (H_x,U_1)=(3,17),(1,12)
\]
となる。同じコア型であっても、向き付きの上界は異なる。

## 3. 196対から109代表

固定点は \(a+b=u\) を満たす対である。このとき gcd 条件は \(\gcd(a,u)=1\) と同値なので、固定点は \(\varphi(u)/2\) 個である。従って Burnside の二元の場合の計数により
\[
 \#\text{反射軌道}=\frac{\#\text{向き付き対}+\#\text{固定点}}2.
\]
また二次 Jordan totient を \(J_2(u)\) と書けば、各幅の対数は
\((J_2(u)-3\varphi(u))/2\)、軌道数は \((J_2(u)-2\varphi(u))/4\) とも書ける。

| \(u\) | 向き付き対 | 固定点 | 代表計算数 | 最小 \(L_1-U_{1,\rm sym}\) |
|---:|---:|---:|---:|---:|
|3|1|1|1|−2|
|4|3|1|2|−1|
|5|6|2|4|1|
|6|9|1|5|0|
|7|15|3|9|2|
|8|18|2|10|4|
|9|27|3|15|7|
|10|30|2|16|8|
|11|45|5|25|14|
|12|42|2|22|12|
|計|196|22|109||

不足する代表は従来どおり \((u,a,b)=(3,1,2),(4,1,3)\) の二つだけであり、どちらも反射固定点である。§14.5、§14.6 の既存処理をそのまま使える。

この109という数は、同じ計算を複製しないための**証明書圧縮**である。実半群の196対を同型で109対に分類したとの主張ではない。新 checker は代表ごとに \(D,H_x,H_v,W\) を計算し、(S5) を使って二向きを一緒に保証する。

## 4. 紙上で幅11を外す：\(\sigma_C\le h+1\)

§14.3 の既存補題を使い、\(h=\lfloor u/2\rfloor\) と置く。混合標準語は
\[
 (s,t)\in D,\quad st>0\quad\Longrightarrow\quad s+t\le h.       \tag{S7}
\]
socle 点が \(q\) 個あるとして、第一座標の昇順に
\((\alpha_i,\beta_i)\)、\(0\le i<q\) と並べる。異なる極大点なので第一座標は厳密増加、第二座標は厳密減少し、
\(\alpha_i\ge i\)、\(\beta_i\ge q-1-i\) である。
\(q\ge h+2\) と仮定すると \(h\ge1\) なので \(q\ge3\)、かつ \(i=1\) の点は
\[
 \alpha_1\ge1,\quad \beta_1\ge q-2\ge h\ge1,\quad
 \alpha_1+\beta_1\ge q-1\ge h+1.
\]
これは (S7) に反する。よって
\[
 \boxed{\sigma_C\le h+1}.                                    \tag{S8}
\]
この補題には新しい公刊入力や有限計算は要らない。

§14.5 の \(\sigma_C\le h+2\) を (S8) に換えると、第一行の一般上界は1減り、(N20) の差は
\[
 \begin{cases}
 \dfrac{h(h-7)}2+1,&u=2h,\\[2mm]
 \dfrac{h(h-5)}2,&u=2h+1.
 \end{cases}                                                \tag{S9}
\]
偶数の cutoff は従来の \(u\ge14\) のままだが、奇数は \(u\ge11\) で閉じる。特に \(u=11\)、\(h=5\) では
\[
 P_C\le29,\quad \sigma_C\le6,\quad R\le W-u\le20,
 \quad\beta_1\le29+6+1+20=56=L_1(11).
\]
したがって有限領域は \(u=3,4,5,6,7,8,9,10,12\) となり、**151向き付き対、固定点17、84反射代表**である。幅11の45対・25軌道は、新しい紙上補題で有限計算そのものから除かれる。

## 5. 幅3、4を紙上で記述すれば81代表

小幅の標準商は直接次のように書ける。\(y,z\) はその行に対応する内部変数である。

| \((u;a,b)\) | \(Q_C\) | \((P_C,\sigma_C,H_x,H_v,W)\) | \(U_{1,\rm sym}\) |
|---|---|---|---:|
|\((3;1,2)\)|\(k[y,z]/(y,z)^2\)|\((3,2,0,0,3)\)|6|
|\((4;1,2)\)、反射 \((4;2,3)\)|\(k[y,z]/(y^2,z^2)\)|\((4,1,1,0,5)\)、反射で高さ交換|6|
|\((4;1,3)\)|\(k[y,z]/(yz,y^3,z^3)\)|\((5,2,1,1,5)\)|8|

商の記述は各関係の端点表示で確認できる。例えば \((u;a,b)=(4;1,2)\) なら \(y^2=xz\)、\(z^2=xv\) で \(yz\) は端点表示を持たない。\((4;1,3)\) なら \(yz=xv\)、\(y^3=x^2z\)、\(z^3=yv^2\) で、\(y^2,z^2\) は残る。幅3も各二次内部語が端点表示を持つ。

幅4の非固定軌道は \(6<7=L_1(4)\) で完了する。残る二固定点は既存本文と同じく、\(d\ge2\) なら物理幅の下界で払える。\(d=1,u=3\) は source と target が同じ、\(d=1,u=4,(a,b)=(1,3)\) は既存 §14.6 の一族である。

この三つのコア型を紙上ケースとして書けば、有限 checker は **81代表**を計算し、それらはすべて (S5) を通る。最小余裕は0である。三つの小コア型が数学的な議論から消えるわけではなく、有限プログラムから紙上計算へ移る。

## 6. unit 倍による追加同一視は使えない

巡回群の unit 倍は \(W\) を保存するが、斉次端点商は一般に保存しない。最小の具体例は
\[
 u=5,\qquad \{1,4\}\xrightarrow{\times2\bmod5}\{2,3\}.
\]
両者とも \(W=7\) だが、標準語はそれぞれ
\[
 \{1,y,y^2,y^3,z,z^2,z^3\},\qquad
 \{1,y,y^2,z,z^2\}
\]
なので \(P_C=7\)、\(5\) と異なる。\(\sigma_C=2\) はこの例では等しい。従って unit 軌道を一代表の \(P_C\) で評価する方法は正しくない。各 unit 軌道の最大値を別途保証すれば新しい有限上界にはなるが、それには新たな補題か全 member の計算が必要である。本調査ではそのような追加同一視を採用していない。

